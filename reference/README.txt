===================================
  Reference Folder / 参考资料文件夹
===================================

This folder is for storing reference materials (images, videos, screenshots, etc.)
that will be used to recreate the target video/animation.

此文件夹用于存放参考素材（图片、视频、截图等），
用于帮助重现目标视频/动画效果。

How to use / 使用方法:
---------------------
Upload your reference files (screenshots, video clips, etc.) into this folder.
将你的参考文件（截图、视频片段等）上传到此文件夹中。

Supported formats / 支持的格式:
- Images: .png, .jpg, .gif
- Videos: .mp4, .webm, .mov
- Documents: .txt, .md

Note: This file does not affect any project functionality.
注意：此文件不影响项目的任何功能。
